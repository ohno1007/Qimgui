# MD3 主界面

`AImGui` 的顶部应用栏、导航、页面、表单和反馈统一使用原生 MD3 组件。概览、组件、设置、性能和关于五页使用同一套主题、Roboto 400／500 与设备中文字体回退。组件页提供基础交互样例，以及复用 `Showcase()` 的八类完整组件展示，其中“形状”分类包含 [MaterialShapes 的 35 种预设](MD3_SHAPES.md)，“表现力组件”分类展示 [四类 Expressive 组件](MD3_EXPRESSIVE.md)。独立的 [MD3Demo](MD3_DEMO.md) 继续用于组件隔离测试。

顶部只有一个“液体玻璃”效果开关。关闭时使用 MD3 实色表面；开启且屏幕采集可用时，窗口与导航背景叠加玻璃材质，页面、控件、主题和交互状态保持不变。采集启动中、不可用或失败时保留实色界面，并显示相应状态。组件页和设置页没有额外玻璃、屏幕镜像或辉光开关。

## 布局与设置

主窗口沿用左右布局：左侧始终显示带图标和文字的 MD3 导航，右侧显示当前页面。侧栏宽度随窗口适当调整，窄屏通过限制显示比例为两栏保留空间。缩放窗口或旋转屏幕后仍保持左右排列。

新配置默认使用居中的 900 × 620 像素横向浮窗，小屏幕按可用范围适配。旧配置中的纵向长窗口在首次显示时改为横向尺寸；之后可继续从右下角调整大小。移动和缩放过程中保持用户设置的位置与大小。

设置页提供深色主题、显示大小、窗口归中、触感反馈、窗口内触摸拦截与防录屏。显示大小的自动／小／标准／大同时调整字体、控件与间距；自动比例根据屏幕与浮窗尺寸计算，并按可用空间限制，不是独立的字号设置。拖动标题可移动窗口，右下角可调整窗口大小，顶部收起按钮或音量键可收起／恢复。

主题、显示比例、玻璃开关、触摸偏好、当前页面与窗口位置／大小使用主程序配置保存。旧配置继续兼容，缺失的新字段使用默认值，非法比例和窗口尺寸会被修正。组件演示的计数、输入与选择状态保留于当前进程，重启后重新开始。

导航与应用栏使用语义轮廓矢量图标，例如 `@home`、`@widgets` 和 `@settings`。这些图形按 24 单位网格绘制，无需图标字体，并非官方 Material Symbols 字形的精确复刻。MD3 令牌、官方源码版本及对照范围见 [MD3_REFERENCE.md](MD3_REFERENCE.md)。

## 真机测试样例

按 [README](../README.md) 构建并以 root 运行 `AImGui`；测试时先退出 `MD3Demo`，避免同时读取触摸设备。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 五页导航 | 依次打开概览、组件、设置、性能、关于，再使用概览快捷入口 | 选中项和标题一致；各页内容、滚动与按钮可达 |
| 状态保留 | 在组件页计数、修改选择和输入名称，连续开关液体玻璃 20 次，再往返其他页面 | 页面、计数、选择、输入和主题不被重置；关闭后恢复实色表面 |
| 主题 | 在实色和玻璃两种状态下切换深色主题 | 应用栏、导航、卡片、表单与弹窗同步变化，文字和选中态可辨认 |
| 左右布局 | 调整窗口和显示大小，在横竖屏及窄窗口下切换五个页面 | 带图标和文字的导航始终位于左侧，页面位于右侧；两栏不重叠，导航与内容均可操作 |
| 默认浮窗 | 使用默认配置启动，或载入旧版纵向长窗口配置，然后拖动和调整大小 | 首次显示为较矮的横向浮窗并居中；之后不会在移动或缩放时反复复位 |
| 表单与反馈 | 空名称保存；填入示例后保存，分别取消和确认 | 空值显示错误；取消不提交；确认显示已保存名称和 Snackbar |
| 配置持久化 | 修改主题、显示大小、玻璃开关与触摸偏好，移动窗口、切页，确认退出后重启 | 偏好、页面与窗口恢复；窗口超出当前屏幕时被限制到可见范围 |
| 触摸与窗口 | 开关窗口内触摸拦截，拖动、调整大小、归中，音量键收起／恢复 | 拦截按设置生效；窗口外操作可转发；收起后交互范围随可见窗口更新 |
| 旋转 | 在实色与玻璃状态下分别旋转设备，再恢复原方向 | Surface 与触摸坐标更新，窗口保持可见，页面状态保留 |
| 全屏录制 | 关闭顶部“液体玻璃”和设置页“防录屏”，系统录屏选择整个屏幕；操作窗口后停止录制并播放 | 录像包含窗口和页面操作；以保存的视频为准 |
| 录屏恢复 | 保持玻璃关闭，先开启再关闭“防录屏”；停止录屏后重新开始整个屏幕录制，操作窗口并播放视频 | 关闭防录屏后的新录像包含窗口；停止、重启录屏后仍可见 |
| 采集回退 | 在采集不可用或启动失败的设备上打开玻璃 | 界面显示状态并保持可操作的 MD3 实色表面；仍可关闭已请求的效果 |
| 退出 | 打开退出确认，先取消，再确认 | 取消后继续使用；确认后保存配置、结束进程并释放触摸拦截 |

文本输入当前需要外接键盘；“填入示例”允许只用触屏走完保存流程。防录屏、触摸转发、屏幕采集和旋转依赖设备系统实现，应同时记录 Android 版本与所用 GLES／Vulkan 后端。

## 主机回归与截图

```bash
tests/run_md3_checks.sh
tests/run_md3_main_checks.sh
tests/run_config_checks.sh
python3 -m pip install -r tests/requirements.txt
build/md3-main-checks/md3-main-test --capture build/md3-main-captures \
  tests/md3_web/fonts/Roboto-400.ttf tests/md3_web/fonts/Roboto-500.ttf
python3 tests/render_md3_main.py build/md3-main-captures --output build/md3-main-preview
```

主界面测试直接运行 `jni/src/ui/ui.cpp` 和 `main_ui.cpp`，使用实际输入事件验证导航、设置、玻璃开关、组件状态、对话框、窗口操作和退出。配置测试覆盖旧字段兼容、新字段持久化及无效值处理。测试程序导出实际 ImGui 绘制数据与玻璃区域；截图脚本在合成测试背景上运行生产 GLES 玻璃着色器，再绘制 MD3 界面，输出 PNG 和包含着色器哈希、渲染器信息的 `manifest.json`。

这些图片是主机软件预览，不是 Android 真机截图，也不能验证设备屏幕采集或 Vulkan 导入路径。主机中文使用 Noto Sans CJK，Android 使用系统字体回退。设备 Surface 生命周期、触摸转发、旋转和两种后端的效果仍需按上表验证。

实时玻璃通过全局采集排除标记避免窗口被采进自己的背景，这也会影响系统录屏。录制窗口的测试应同时关闭玻璃和防录屏；目前未实现冻结背景再录制玻璃窗口的路径。主机回归不能代替对保存视频的真机检查。
